# 📊 AI 台股分析報告集

本目錄收錄 **Hermes AI 分析系統** 每日/每週產出的台股盤後分析報告。

> ⚠️ 本目錄與本 repo 的 `analyzer.py`（舊版 Python 分析系統）是**兩套獨立系統**。
> 舊系統的產出在 `data/` 與 `_site/`；AI 分析報告在 `reports/`。
> 兩者共存，AI 報告可作為舊系統未來改進的學習資料。

---

## 📁 目錄結構

```
reports/
├── README.md              ← 本檔案
├── daily/                 每日盤後分析報告
│   ├── 2026-07-21.md
│   ├── 2026-07-22.md
│   └── ...
└── weekly/                每週預測準確度檢討報告
    ├── Week-29-20260713.md
    ├── Week-30-20260720.md
    └── ...
```

**命名規則**
- 日報：`YYYY-MM-DD.md`（同日若有多版，取最後產出的一份）
- 週報：`Week-<ISO週數>-<該週週一日期>.md`

## 📋 報告格式（供程式解析）

每份日報包含以下固定章節：

```markdown
【台股大盤動態觀測】
- 今日收盤/漲跌/成交量
- 資金風向與技術面狀態

【50元以下潛力股深度解構】
（每檔個股：四維度分析 + 明日股價預測 + 昨日落差分析）

【預測錯誤檢討學習區】
（逐檔比對昨日預測 vs 今日實際，歸納錯誤類型）

【明日大盤方向綜合研判】

【未來性綜合結論與風險提示】
```

### 四維度分析（每檔個股）

| 維度 | 內容 |
|:-----|:-----|
| 📰 消息題材 | 新聞、產業趨勢 |
| 📊 技術資金 | 均線、KD、量價、籌碼 |
| 💰 財務底氣 | EPS、營收、配息 |
| 🏰 戰略護城河 | 競爭優勢、產業地位 |

### 錯誤類型分類（在「預測錯誤檢討學習區」）

- `🏭 產業面誤判` — 錯估產業趨勢或利多/利空影響
- `📊 技術面誤判` — 均線/KD/量價給錯訊號
- `🌍 大盤/國際面干擾` — 系統性風險或國際盤勢
- `📰 突發事件` — 盤中未預期新聞
- `🎯 其他` — 籌碼面、特定大戶動作

## 🤖 未來學習用途建議

這些報告的價值不只是「看盤紀錄」，更是**分析邏輯的可回測資料集**：

### 1. 預測準確度回測
- 報告中含「明日股價預測區間」→ 可與隔日實際走勢比對
- 累積足夠樣本後，可統計各產業/各技術型態的預測命中率
- 找出「哪些條件下的預測特別不準」→ 改進舊系統的評分權重

### 2. 錯誤模式學習
- 「預測錯誤檢討學習區」已人工歸類錯誤類型
- 可直接抽取作為**訓練/規則調整資料**（例如：KD 黃金交叉在 5MA 下彎時失效）
- 累積後可建立「錯誤觸發條件」清單，自動避開已知陷阱

### 3. 選股邏輯驗證
- 對照舊系統（`analyzer.py`）的篩選結果 vs AI 報告的選股 → 找出差異
- 分析「AI 選到但舊系統沒選」或反之的案例，互相校正

### 4. 產業趨勢追蹤
- 長期累積可看出產業輪動（哪些題材連續被提及、熱度變化）
- 作為舊系統產業權重調整的依據

## 🔄 自動同步機制

- **每日 23:00** 由 Hermes cron 自動同步（日報 22:00 產出後）
- 同步腳本：`~/.hermes/scripts/sync-stock-reports.sh`
- 報告來源：
  - 日報：`~/.hermes/cron/output/2b7d1c0ba906/`
  - 週報：`~/Documents/StockAnalysis/<year>/Week-*/`
- 同步後自動 `git commit` + `git push`

**報告由 Hermes AI 系統產出，非本 repo 的 analyzer.py。**
