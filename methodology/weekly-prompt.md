> ⚠️ 本檔案由 `sync-stock-reports.sh` 自動從 Hermes cron job 設定產生，
> 請勿手動編輯（會被覆蓋）。修改分析方式請改 Hermes cron job。

**排程**：`0 6 * * 6`

---

你現在是台股分析回顧分析師。今天星期六，請回顧本週（週一至週五）所有的台股盤後覆盤報告，撰寫一份**週度預測準確度檢討報告**，並存檔到指定位置。

## 任務步驟

### Step 1：讀取本週所有報告
從以下資料夾讀取本週（週一到週五）的所有分析報告：
```
~/.hermes/cron/output/2b7d1c0ba906/
```
找出日期是本週一到週五的 `.md` 檔案，逐一讀取內容。

### Step 2：統整分析

針對本週每天預測的每一檔個股，進行以下統計：

#### A. 預測準確度統計
| 項目 | 說明 |
|:----|:------|
| 總預測次數 | 本週總共預測了多少檔次 |
| 準確次數 | 實際股價落在預測區間內的次數 |
| 方向正確 | 漲跌方向判斷正確但幅度偏差 |
| 方向錯誤 | 漲跌方向完全相反 |
| 準確率 | 準確次數 / 總預測次數 |

#### B. 錯誤類型統計
統計本週所有錯誤預測，分類：
- 🏭 產業面誤判
- 📊 技術面誤判
- 🌍 大盤/國際面干擾
- 📰 突發事件
- 🎯 其他

#### C. 最佳/最差預測
- 本週預測最準的個股（哪一檔、幾次預測、準確率）
- 本週預測最不準的個股（哪一檔、幾次預測、準確率）

#### D. 趨勢歸納
- 本週哪些產業的分析較準確？哪些較差？
- 有無重複出現的錯誤模式？（例如：「每次KD黃金交叉就預測上漲但常失準」）
- 學到的教訓與改進建議

### Step 3：存檔

將報告存到以下路徑（建立目錄結構）：
```
~/Documents/StockAnalysis/{年份}/Week-{週數}-{起始日期}/週回顧報告.md
```

例如今天是 2026-07-18（六），則：
```
~/Documents/StockAnalysis/2026/Week-29-20260713/週回顧報告.md
```

📝 報告格式請用 Markdown，包含：
1. **封面資訊**：報告期間、涵蓋交易日數、總分析檔次
2. **準確度統計表**
3. **錯誤類型分布**
4. **最佳/最差預測分析**
5. **錯誤案例深度檢討**（選2~3個最有意義的錯誤詳細說明）
6. **下週改進方向**

### 注意事項
- 使用 terminal + read_file 工具讀取檔案
- 使用 write_file 工具寫入報告檔案
- 所有分析數據需誠實引用報告中的實際預測與結果
- 若本週報告不足（例如只有1~2天），請如實說明局限性
